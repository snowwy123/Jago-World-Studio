# Jago World 0.23.0

Give your ideas a world.

Connect characters, lore, scenes, timelines and maps in one editable setting. Build a reference for a story, game or imagined place and share readable views of it.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-World-Studio/releases/latest)

## Get started

Download **Jago-World-v0.23.0.zip**, right-click it and choose **Extract All**. Open **Jago-World.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition. Open **Jago-World.html** for offline browser use in current Edge or Chrome.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-World-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Linked world entries, writing, scenes, maps, timelines and reading views.
- Illustrated or imported character portraits and connected family relationships.
- Family-tree focus, folding, search and styled presentations.
- Map artwork, markers, legends, scale bars, atmosphere and repeatable surfaces.
- World-bible and reference exports; project audio attachments.
- Harbour and landmass generation has more varied coastlines, spacing and small islands.
- Brush-based coastline shaping makes large node sets easier to edit.
- Staged map-surface editing with role previews, scale, rotation and offsets.
- Group-aware alignment, equal gaps and stronger world checks.
- Clearer material/repeat surface workflow; colour tiles remain visual surfaces.
